# Ecosystem — Hệ sinh thái dự án

Trang giao diện chung để quản lý, theo dõi và điều hướng toàn bộ các dự án đang phát triển.

## Mục tiêu

Tự tay tổ chức và làm việc trên từng dự án — không vibe coding, không mất phương hướng.
Xây dựng để duy trì lâu dài, không phải showcase một lần rồi bỏ.

## Giới thiệu

Đây là giao diện trung tâm của hệ sinh thái. Từ đây có thể:

- Xem tổng quan tất cả dự án đang có
- Theo dõi trạng thái và tiến độ từng dự án
- Hiểu quy trình làm việc áp dụng chung
- Truy cập nhanh vào từng dự án con

## Khởi động

```bash
npm install
npm run dev
```
